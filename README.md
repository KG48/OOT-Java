## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/OOT-Java.git
```

Navigate to the repository:

```bash
cd OOT-Java
```

Navigate to a Java program:

```bash
cd 01-Java-Basics
```

Compile the program:

```bash
javac HelloWorld.java
```

Run the program:

```bash
java HelloWorld
```
